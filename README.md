# train-route — 환승 열차 탐색

출발 시각 기준으로 직통·환승 1~2회 조합을 전부 펼쳐 **실제로 가장 빨리 도착하는 열차 조합**을 찾아주는 웹앱.
도착역을 여러 개(예: `천안, 천안아산`) 묶어서 찾을 수 있다.

## 준비
1. https://www.data.go.kr/data/15098552/openapi.do 에서 **활용신청** (개발계정 자동승인, 하루 10,000건)
2. 마이페이지에서 **일반 인증키(Decoding)** 복사
3. `.env.example` → `.env` 로 복사 후 `TAGO_KEY=` 뒤에 붙여넣기

## 실행 (Node 22+, 설치할 패키지 없음)
```
node server.js
```
→ http://localhost:8787

외부(폰)에서 쓰려면 이 서버를 24시간 켜진 PC에서 돌리고 도메인/포트를 연결하면 된다.
인증키는 서버에만 있고 브라우저로 나가지 않는다.

## 동작 방식
- TAGO API는 "A역→B역" 구간 단위로만 열차를 준다 → 출발역·환승 후보역·도착역 사이 구간 시간표를 모아 이어붙임
- 구간마다 "탈 수 있는 열차 중 가장 일찍 도착하는 열차"를 선택, 최소 환승 여유 시간 적용
- 결과는 "더 늦게 출발 / 더 일찍 도착 / 환승이 적음" 중 하나라도 나은 경로만 남김(파레토)
- 구간 시간표는 `cache/` 에 날짜별 저장(6시간), 역 목록은 30일 캐시

## 알려진 한계
- 환승 후보역(허브) 목록 밖의 역에서 갈아타는 경로는 못 찾음 → 화면의 "환승 후보역 편집"에서 추가
- 환승 2회는 허브 간 조회가 많아 첫 조회가 느림(같은 날 재조회는 캐시)
- 잔여 좌석은 알 수 없음(공식 API 없음), SRT 포함 여부는 TAGO 데이터에 따름
